Files of code execution: `response.files` (and `CompletedEvent.files`) lists the files Anthropic's code execution wrote, from the `bash_code_execution_output` (and `code_execution_output`) blocks of its results, as `ProducedFile`s with the `source_call_id` of the call; they are stored files, so `client.files.download(file)` and every other files call take them. `CodeExecution(files=[...])` puts stored files into the code's container as `container_upload` blocks at the end of the last `user` message.
